# Product

## Platform

web

## Users

People searching for photos, videos, and GIFs and saving media to a collection.

## Product Purpose

MediaSearch provides media search and a collection for saved items.

## Positioning

No distinct positioning has been established.

## Capabilities and Constraints

The frontend supports searching for photos, videos, and GIFs and saving items to a collection. The backend provides session-based login and registration. The login screen supports both forms and returns users to the main search page after successful authentication.

## Evidence on Hand

The existing frontend and backend code provide the search, collection, login, and registration flows. No additional brand or proof assets are established.
